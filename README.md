# Amogh L — Portfolio Website

A responsive, single-page portfolio built with plain HTML, CSS, and JavaScript. No build tools or dependencies required.

## Run locally
Open `index.html` in your browser.

## Deploy with GitHub Pages
1. Create a new GitHub repository, for example `amogh-portfolio`.
2. Upload `index.html`, `style.css`, `script.js`, and this README to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then click **Save**.
6. Wait for GitHub Pages to publish your site. Your URL will look like:
   `https://YOUR-USERNAME.github.io/amogh-portfolio/`

## Before publishing — personalise these
- Replace the generic GitHub profile link in the contact section with your actual GitHub profile URL.
- Review the project descriptions and add individual repository/demo links where available.
- Optionally add a profile photo in `assets/` and update the hero/about section.
- Confirm contact details are the ones you want publicly visible.
- The portfolio intentionally does not publish your home address, date of birth, or personal phone numbers.
